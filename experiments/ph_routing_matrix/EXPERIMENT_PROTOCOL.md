# Dörfler/LLM 双分区、三执行器与 P–H 动态路由完整实验协议

## 1. 实验所验证的核心命题

本文不把 Dörfler、PSO、DQN、监督学习和 LLM 视为互相替代的完整 AMR 算法，而把系统拆成三个正交层次：第一层是 action-support partition，即从当前有限元证据与任务语义中确定哪些区域允许获得本轮资源；第二层是 regional executor，即在选定区域内确定加密深度、目标尺寸、动作顺序与预算分配；第三层是 P–H router，即根据任务熟悉度、机制可辨识性、模型风险、可用数据先验和真实物理反馈预算选择具体分区—执行器路线。本文的主要假设是，在相同最终误差容限与资源预算下，动态路由能够在已知、低风险任务上利用高先验压缩减少真实求解，在机制冲突、分布偏移或模型失配时降低压缩强度并购买更多真实 FEA，从而比任何固定高压缩路线具有更好的尾部可靠性，并以接近逐实例路线 oracle 的代价达到目标状态。

## 2. 正交方法矩阵

主实验保留用户确认的两类分区与三类执行器，不再把“LLM+PSO”或“Dörfler+DQN”混成不可拆解的整体方法。D 表示 Dörfler marking 式数值分区，L 表示 LLM 机制分区，后缀 D、PSO、DQN 表示分区之后的执行器。

| 编号 | 分区来源 | 执行器 | 在线动作含义 | 主要 P–H 特征 |
|---|---|---|---|---|
| DM_D | 动态 Dörfler marking | Dörfler | 每次真实求解后重新标记，并在标记区内执行标准一级或预设层级加密 | 低 P、较高 H、强物理纠错 |
| DM_PSO | 初始或刷新后的 Dörfler 区域 | PSO | 只在数值分区内优化区域加密层数、尺寸、过渡宽度与粗化比例 | 中等 P、PSO 总 FE 次数较高、顺序 H 可并行压缩 |
| DM_DQN | 动态 Dörfler marking | DQN | DQN 只在当前标记支持内选择区域动作与深度，真实求解后支持可刷新 | 中高 P、中等 H、存在训练方差 |
| LM_D | LLM 机制分区 | Dörfler | LLM 给出机制区域，Dörfler 指标在这些区域内决定实际标记顺序 | 中等 P、较低或中等 H、依赖分区召回率 |
| LM_PSO | LLM 机制分区 | PSO | LLM 定义低维机制区域和变量边界，PSO 完成连续/离散数值定解 | 高 P、低维搜索、总 FE 成本可能较高 |
| LM_DQN | LLM 机制分区 | DQN | LLM 限制动作支持和动作类型，DQN 决定在线序列动作 | 高 P、中等 H、同时承受分区风险和策略方差 |
| SL_ONE_SHOT | 学习到的终态映射 | 监督学习 | 从任务、粗解或几何状态一次预测终态尺寸场，再执行最终真实 FEA 审计 | 最高 P、最低 H、teacher ceiling 与 OOD 尾部风险 |
| LLM_PH_ROUTER | LLM 读取方法卡片和门控证据 | 路由上述路线 | 在执行前选择路线，执行后根据真实审计结果维持、降级或回退 | 动态配置 P 与 H |

标准动态 AFEM 必须作为强安全基线保留；DM_D 的正式实现必须在每次真实反馈后重新计算 Dörfler 支持，不能只使用初始粗网格的冻结支持。DM_PSO 的主版本采用“初始数值分区+区域级 PSO”，因为其科学问题是先压缩空间再进行数值定解；另设“每次刷新分区后重新启动 PSO”的高成本变体作为消融。DM_DQN 的主版本允许数值支持随物理反馈更新，LM_DQN 的主版本保持机制支持，只有机制验收门失败时才允许 LLM 重建分区。

## 3. P、H 与成本的可操作定义

P 不直接等于模型参数量或训练样本数，而表示先验对候选自适应轨迹空间的压缩程度。理论表达可写成候选轨迹条件熵的减少，工程实验中采用可审计的分量近似：支持压缩 `P_support=1-K/N`，其中 N 为可干预区域数、K 为分区后活动区域数；动作压缩 `P_action=1-log(|A_retained|+1)/log(|A_full|+1)`，衡量分区和 skill 约束消除了多少动作组合；轨迹压缩 `P_trajectory=1-H_plan/H_AFEM_ref`，衡量宏动作计划相对参考 AFEM 路径减少了多少顺序反馈；数据/策略先验强度 `P_model` 记录监督标签、DQN 训练分布或 LLM 机制库对在线决策的摊销作用。有效压缩不得直接使用名义值，而写成 `P_eff=P_nominal×c_domain×c_evidence×c_calibration`，其中 `c_domain` 表示任务是否处于训练或 skill 适用域，`c_evidence` 表示 LLM 分区与当前数值证据的一致性，`c_calibration` 表示该路线在独立验证集上的成功率和风险校准。

H 定义为从任务开始到终态验收之间具有顺序依赖的高保真物理反馈深度；共同粗网格真实求解计入第一层物理证据，执行动作后必须等待的新全局 FEA 或等价高保真 patch solve 各增加一层。PSO 同一代的多个粒子若可并行求解，只增加一层顺序 H，但每个粒子求解都必须计入总高保真调用数 `N_FE` 和累计物理工作量 `W_phys`。因此所有实验同时报告 `H_seq`、`N_FE`、`W_phys=Σ C_solve(T_i)`、墙钟时间、训练/标签成本 `W_prior` 和最终网格资源 `C_final`，防止某个方法通过隐藏大量并行求解获得表面上的低 H。

## 4. LLM 机制分区的输入、输出与边界

LLM 分区不允许只读取几何截图并圈孔、圆角或高应力颜色区域，也不允许直接猜测 θ、尺寸或加密倍率。输入必须是结构化任务契约与物理证据，包括 PDE/本构类型、材料与界面、载荷和边界条件、QoI、误差容限、最终预算、允许反馈次数、粗网格拓扑、粗解场、局部误差指标、网格质量、历史动作与 skill 适用域。输出是可验证的 mechanism partition contract，每个区域包含区域边界、候选误差机制、支持证据、竞争机制、与 QoI 的关系、预计持续性、允许动作类型、参数范围、耦合区域、置信度、最小辨识探针、证伪条件和回退路线。LLM 只能定义机制结构、区域和可行变量域；连续数值参数由 PSO、MILP、动态规划或局部响应拟合 skill 求解，最终误差与网格质量由真实 FEA 和后验估计器裁决。

正式实验同时保留三种 LLM 条件：几何显著性分区，用于模拟 GReFEM 式直接圈区域；直接参数猜测，用于模拟 SimulCost 式连续调参；完整机制分区，用于验证本文方法。若完整机制分区不能在相同执行器下提高有限 H 的成功率、降低路径成本或改善 OOD 失效检测，它就不能被解释为有效机制推理。

## 5. P–H 路由器与限制门

路由器输入由 task contract、两类分区、分区一致性、粗解指标集中度、机制熟悉度、DQN/监督模型不确定性、skill 适用域、各路线独立验证方法卡片、剩余预算与风险上限组成。路由不应仅使用一个任意加权和，而采用受约束选择：在候选路线中最小化预计 `W_phys+λW_prior`，满足 `Pr(E≤ε,C_final≤B)≥1-δ`、`H≤H_max` 和 skill 适用域约束；若没有高压缩路线满足可靠性约束，系统必须 abstain 并选择动态 DM_D 或增加辨识探针。

限制门至少包括：任务门，QoI、误差与预算缺失时禁止规划；证据门，机制区域必须绑定具体几何、场量或指标证据；可辨识门，竞争机制导致不同动作而当前证据不足时必须购买探针；数值门，LLM 只给结构和范围，数值由 skill 定解；适用域门，监督模型、DQN、PSO 响应模型或 LLM skill 超域时降低 P；风险门，高影响高不确定区域禁止无审计 one-shot；物理验收门，预测误差下降、热点迁移或成本增长与真实结果不一致时必须降级路线或重建机制模型。

## 6. 数百算例的正式物理库

主论文的二维 CalculiX/平面弹性库采用十个机制家族、六个几何参数实例、两个载荷状态、两个 QoI 和三个预算层级，共 `10×6×2×2×3=720` 个独立测试任务。十个机制家族为：平滑无持续热点；圆孔/椭圆孔有限尺度应力集中；圆角/光滑缺口高梯度；L 形域或重入角奇异性；材料界面或夹杂；单一局部载荷或边界层；双热点/多热点有限预算竞争；任务相关性错位的诱饵几何或诱饵高应力区；方向性强的各向异性热点；由孔、界面、局部载荷或奇异角组合形成的复合机制。几何实例必须改变位置、尺度、偏心、孔形、界面位置和特征间距；载荷状态改变方向、位置和分布；QoI 至少包含全局能量/位移和局部应力或局部位移；预算采用紧、中、宽三档并保证一部分任务确实不可在最低预算内达到容限，以测试系统的风险识别而非只测试平均精度。

测试集按机制而不是随机样本拆分：参数内分布测试 360 例，几何或参数外推 180 例，已知机制的新组合 120 例，QoI/预算任务偏移 60 例，总计 720 例。DQN 与监督学习训练数据由前八个单机制家族的独立参数域生成，训练几何、验证几何和测试几何不能共享同一模板参数；复合机制与部分任务偏移严格不进入训练。监督标签分别采用长程动态 AFEM 终态、预算内离散 oracle 和均匀高密参考，以分离 teacher bias。DQN 至少保存五个独立训练种子，PSO 至少运行五个群体种子，监督模型至少运行三个训练种子；确定性 AFEM 运行一次，但初始网格扰动仍作为独立物理实例。

三维外部验证库不需要重复 720 例，可采用六个结构模板、四个参数实例、两个载荷、两个预算，共 96 例，模板包括带孔或加劲板、连接板/节点板、横向通道空间桁架、局部锚固或支承区、桥梁构件局部细节和复合界面构件。三维库的作用是验证方法矩阵和路由原则能否迁移，不承担训练大规模监督模型的主要统计任务。

## 7. 鲁棒性与失效注入库

从 720 个主测试任务中按机制、预算和 QoI 分层抽取 120 例，每例依次施加六类单因素扰动，形成额外 720 个鲁棒性任务：粗网格旋转、尺寸和拓扑扰动；局部误差指标加入 10%、20%、40% 噪声或漏报；LLM 分区随机遗漏一个真实热点、扩大一个无关区域或交换热点优先级；监督模型与 DQN 遇到未见 QoI、材料比或机制组合；PSO 粒子数、代数和代理精度被限制；求解器或 skill 返回超时、无效网格或不一致结果。每个扰动都报告失效检测率、错误路线率、回退触发率、回退后恢复率、额外 H、额外 N_FE 和最坏 10% 误差，而不只报告最终平均成功率。

LLM 本身的随机性在 120 个高歧义样本上单独评估，采用至少三个模型、每个模型五次独立调用；温度零的冻结合同版本用于大规模可复现主实验，随机调用版本用于评估分区一致性、机制解释稳定性和路由方差。模型名称、版本、日期、system prompt、skill 版本、输入哈希与原始结构化输出全部保存，避免把不可复现的聊天结果当作算法证据。

## 8. 公平性控制

所有路线共享相同初始网格、材料与边界条件、粗解、最终误差审计器、资源预算、网格质量约束和终止准则。Dörfler、PSO、DQN 的局部价值均从统一精度—资源目标派生，分区只改变动作支持，执行器只改变支持内部的动作定解方式。PSO 每一个调用真实 CalculiX 的粒子都计入 N_FE 和 W_phys；DQN 在线每一次依赖新 FE 状态的动作都计入 H；监督与 DQN 的训练数据生成成本单独记录并按部署次数摊销；LLM token、推理时间和调用失败计入 W_prior 与系统墙钟时间。禁止使用测试参考解生成 LLM 分区、路由特征、PSO fitness 或 DQN 在线状态，参考解只用于离线教师、最终评价和逐实例 oracle。

## 9. 主要评价指标与统计检验

第一层网格质量指标为最终综合误差 E、QoI 误差、自由度/单元数、内存和最终求解时间，以及到每个算例离线 E–C Pareto 前沿的距离。第二层系统指标为约束成功率、H_seq、N_FE、W_phys、W_prior、总墙钟时间、P_eff、路线选择频率、routing regret、失败检测率、回退恢复率和 CVaR90/CVaR95 尾部误差。逐实例路线 oracle 定义为所有达到约束的固定路线中 `W_phys+λH` 最小者，若没有路线成功，则使用误差最小者；路由器无需每次命中 oracle，但应在成功率和成本上接近 oracle 包络。

主比较采用配对算例作为统计单位，随机种子先在算例内聚合，不能把每个 PSO 粒子或 DQN episode 当作独立样本。成功率差异使用配对 bootstrap 置信区间和 McNemar 检验，连续成本与误差使用配对 bootstrap、Wilcoxon signed-rank 或具有机制家族随机效应的混合模型；多方法比较执行 Holm 校正。必须报告均值、中位数、标准差、95% 置信区间和最坏尾部，不能只报告单个最佳种子。

## 10. 核心消融

消融至少包括：仅用动态 DM_D；Dörfler 分区固定支持与动态支持；LLM 分区固定支持与物理否定后更新；LLM 直接圈区域；LLM 直接猜参数；LLM 机制分区但无 skill 数值定解；有 skill 但无适用域门；有方法卡片但不使用 P–H；固定高 P 路线；固定低 P 路线；取消物理验收；取消回退；用随机或几何显著性分区替代机制分区；监督模型使用不同 teacher；DQN 使用相同网络但交换分区支持。通过两因素模型检验“分区来源×执行器”交互，回答收益究竟来自 LLM 分区、PSO/DQN 执行器还是二者组合。

## 12. 预先规定的判据

为了避免事后挑指标，正式实验开始前固定主要成功判据：动态路由在总体和机制 OOD 上的约束成功率不得低于最佳固定可靠路线超过两个百分点；在达到相近成功率的样本上，中位 H 或 W_phys 至少有一个相对动态 DM_D 降低 20%；routing regret 的中位数接近零且 90% 分位受控；无门控高 P 路线发生失效时，完整系统的检测与回退恢复率显著提高；LM 分区相对 DM 分区的收益必须在至少一个执行器上通过配对统计检验，并且不能只来自最终使用更多单元。若动态 DM_D 在全部机制上同时具有最高成功率和最低成本，应如实报告当前问题不需要复杂路由，并把贡献边界限定到更强有限 H、复合机制或重复部署条件。

## 13. 已完成的 Stage-0 实现与首批结果

当前代码已经生成 384 个参数化真实有限元任务，按 168 个训练、84 个独立验证和 132 个测试划分；测试中包含 48 个完全留出的 mixed_shift 复合机制。每个候选网格都实际装配并求解空间变系数一维椭圆有限元系统，完成 DM_D、DM_PSO、DM_DQN、LM_D、LM_PSO、LM_DQN、SL_ONE_SHOT 和冻结 LLM P–H 路由，三个算法随机种子共享同一物理算例。三种子平均测试成功率分别为 DM_D 0.924、DM_PSO 0.783、DM_DQN 0.760、LM_D 0.788、LM_PSO 0.846、LM_DQN 0.720、SL_ONE_SHOT 0.538、LLM_PH_ROUTER 0.924；DQN 路线出现明显种子方差，one-shot 监督在分布偏移下具有最低反馈但最差尾部可靠性，动态路由维持了与强 DM_D 相同的成功率，却尚未降低平均 H 和 N_FE。这个结果说明协议已经工作，同时也否定了“加入路由自然就会胜过 AFEM”的弱结论；下一阶段必须在有限 H 更紧、机制组合更复杂的二维/三维 CalculiX 任务上验证路由价值，并改进对高成本 PSO 路线的价值评估。

## 14. 与现有 CalculiX 仓库的迁移接口

Stage-0 的 `CaseSpec`、`PartitionResult`、`MethodResult`、`P-H method card`、`RouteDecision`、逐实例 oracle、结果 CSV 和图形接口可以直接迁移到已有横向通道 CalculiX 基准。Dörfler 分区模块替换为真实残差/ZZ/QoI 指标与连通区域聚合；LLM 分区模块读取几何、材料、边界、粗网格场和 skill 证据并输出区域 ID；PSO 将八区域级别向量替换为真实区域目标尺寸、层数和过渡宽度；DQN 将一维状态替换为已有 GCN 区域特征；监督模型预测 CalculiX sizing field；路由器保持方法卡片、P_eff、H、风险门和回退协议不变。工程上的 Agent、MCP、日志和求解器封装只负责执行这套实验合同，不改变本文核心科学变量。
