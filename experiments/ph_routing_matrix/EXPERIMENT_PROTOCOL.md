# 当前 Dörfler 热点的跨轮次资源重投与 P–H 路由实验协议

## 1. 科学命题

本研究接受局部误差估计和 Dörfler marking 对当前状态的有效性。经典 Dörfler 回答“这一轮哪些单元值得加密”，但通常通过多轮真实 FEA 逐步发现这些区域最终需要多少累计资源以及后来会出现哪些新热点。人工专家能够根据机制、粗网格证据和经验，判断某些当前热点将连续命中若干轮，于是提前深加密，并只保留少量真实求解用于发现新热点和纠错。本文检验受 Skill 和限制门约束的 LLM 能否复现这一资源重投过程，并由 P–H 路由器决定何时采用高先验压缩、何时保留更多物理反馈。

## 2. 统一在线起点

所有方法必须共享同一任务合同、初始网格、真实粗网格 FEA、局部误差指标、Dörfler 参数和第一次当前热点支持。LLM、PSO、DQN 和监督模型都不得使用隐藏参考解、长程 Dörfler 终态或测试标签。当前 Dörfler 支持可以按连通性和共同机制聚合为区域，但任何数值高指标单元不得因自然语言解释不足而被静默删除。

## 3. 预测对象

LLM 的主要输出不是另一张独立热点图，而是每个当前资源区域的未来持续性和累计动作结构：未来重复命中次数分布、建议目标网格级别、加密深度区间、区域扩张概率、收益饱和点、置信度、中间审计需求和证伪条件。形式上，给定第一次状态与支持 `M_0`，预测 `n_i^future` 或累计深度 `d_i*`，近似压缩长程轨迹中 `Σ_t 1[R_i∩M_t≠∅]`。当证据提示后续热点可能迁移或扩展时，系统必须设置至少一个真实 FEA 检查点。

## 4. Skill 链

执行链固定为：`compile_task_contract → solve_coarse_and_mark → aggregate_current_support → derive_theory_and_coarse_evidence → predict_future_hits_and_depth → assess_ph → select_delegation_route → solve_numeric_depth_if_needed → execute_macro_action → audit_true_fea → refresh_dorfler_support_or_stop → calibrate_ph_gap`。理论 Skill 提供局部正则性、奇异阶、界面尺度、边界层宽度、QoI 灵敏度或误差传播结构；粗网格 Skill 提供指标密度、恢复梯度、网格分辨率和当前支持；PSO/MILP/动态规划/DQN只在压缩后的区域动作空间内求具体数值；真实 FEA 和后验估计器保留最终裁决权。

## 5. 固定路线

正式固定路线包括：`DORFLER_H2/H3/...`，在给定 H 上限下逐轮一级加密；`INDICATOR_DELEGATE`，仅由当前指标幅值决定一次重投深度；`LLM_DELEGATE`，由机制合同一次预测当前热点累计深度；`LLM_DELEGATE_GUARDED`，机制重投后按风险触发一次动态 Dörfler 校正；`LLM_TWO_STAGE`，先重投当前持续热点，再经一次真实 FEA 刷新支持并处理新热点；`D_SUPPORT_PSO`，在共同当前支持内无机制中心地搜索深度；`LLM_PSO`，以机制预测为搜索中心定解；`D_SUPPORT_DQN` 与 `LLM_DQN`，使用相同策略网络但分别接受纯数值支持和机制持续性特征；`SL_ONE_SHOT`，从粗解一次预测终态配置；`PH_ROUTER`，根据校准后的成功概率、P、H、N_FE、W_phys、任务风险和剩余预算选择路线。

标准动态 Dörfler 是独立基线，不再写成一个虚假的“Dörfler 分区+Dörfler 执行器”新方法。所有分区/执行器比较都应理解为相同当前误差证据下的资源深度和轨迹压缩比较。

## 6. 两个离线 Oracle

`ORACLE_CURRENT_SUPPORT` 知道初始当前支持内部的真实未来命中次数，但不能处理后来出现的热点；它给出“只解决当前热点加多深”的理论上限。`ORACLE_FULL_TRAJECTORY` 知道整个长程动态 Dörfler 的终态级别和后来热点；它给出完整 trajectory compression 上限。两者的成功率、误差和成本差直接量化支持刷新是否具有结构性必要。

## 7. P、H 与成本

P 表示先验对未来 refinement trajectory 的压缩程度，不等于模型参数量。至少记录支持压缩、动作压缩、轨迹压缩和求解替代四个分量；执行前得到 `P_hat`，执行后依据实际动作、回退和物理工作重算 `P_exec`。H 是顺序依赖的高保真物理反馈深度，共同粗解、宏动作后的全局审计和后续支持刷新均计入；PSO 同代候选即使并行，只增加一层 H，但每个真实候选都计入 N_FE 和 W_phys。最终同时报告 H、N_FE、W_phys、墙钟时间、训练/标签成本和最终网格资源，禁止用并行搜索隐藏物理成本。

## 8. 主要指标

主要判据是 `Pr(E≤ε,C_final≤B)`、`success | reference-feasible`、达到容限的最小 H、相同 H 下误差、E–C Pareto 距离、N_FE、W_phys、成功样本节省轮次、未来命中次数 MAE/Brier/ECE、累计深度偏差、后来热点漏检率、过度重投率、回退率、回退恢复率、routing regret 和 CVaR90/95。热点当前召回仅作为安全审计，不能替代跨轮次效率指标。

## 9. Stage-0B 设计与结果

Stage-0B 使用 384 个参数化一维变系数椭圆 P1 有限元任务和三个算法随机种子；测试集 174 例，其中 139 例在长程动态 Dörfler与资源上限下可达到 0.005 误差容限。三种子均值为：DORFLER_H2 总体/条件成功率 0.310/0.388，H=1.83；DORFLER_H3 为 0.431/0.540，H=2.52；INDICATOR_DELEGATE 为 0.299/0.353，H=2.00；LLM_DELEGATE 为 0.351/0.417，H=2.00；LLM_DELEGATE_GUARDED 为 0.506/0.612，H=2.64；LLM_TWO_STAGE 为 0.678/0.791，H=2.64，并在成功样本中平均节省 0.62 轮；SL_ONE_SHOT 为 0.477/0.583，H=2.00；ORACLE_CURRENT_SUPPORT 条件成功率 0.583，而 ORACLE_FULL_TRAJECTORY 为 1.000。该结果支持“重投可以压缩反馈，但后来热点使少量支持刷新具有必要性”，同时否定“只要预测初始热点深度就可稳定 one-shot”的过强主张。

D_SUPPORT_PSO 平均 N_FE 为 7.65，LLM_PSO 为 5.77，两者当前未形成反馈压缩优势；初版 PH_ROUTER 约为 0.444 总体成功率并过度购买 PSO，必须用执行 PH 偏差、后来热点风险和 W_phys 重新校准。冻结机制合同的 future-hit MAE 尚未优于指标映射，这一负结果保留。

## 10. 正式二维/三维实验

二维 CalculiX 主库仍采用 10 个机制家族×6 个几何实例×2 个载荷×2 个 QoI×3 个预算，共 720 个任务；机制包括平滑场、有限尺度应力集中、重入角奇异性、材料界面、边界层、多热点预算竞争、诱饵 QoI、各向异性和复合机制。每个算例先运行长程动态 Dörfler生成 future-hit/depth 审计标签，再在只暴露第一次或前两次证据的条件下运行固定路线和 PH 路由。三维桥梁迁移库为 96 例。DQN 至少五个训练种子、PSO 五个搜索种子、监督模型三个训练种子；高歧义子集采用三个 LLM、每个模型五次独立调用。

## 11. 鲁棒性实验

从主测试库分层抽取 120 例，分别注入粗网格变化、指标噪声或漏报、错误持续性先验、后来热点迁移、理论 Skill 超域、DQN/监督 OOD、PSO截断以及求解器/网格失败。比较无审计重投、两阶段重投、完整门控路由和动态 Dörfler，报告错误接受、失效检测、回退恢复、额外 H/N_FE/W_phys 与尾部误差。

## 12. PH 评估—执行差距图

每个方法和任务在执行前冻结 `(P_hat,H_hat)`，执行后从真实轨迹重算 `(P_exec,H_exec)`。脚本使用空心点显示评估值、实心点显示执行值、箭头显示偏差、误差条显示跨算例/种子区间，点大小显示 N_FE 或 W_phys；同时输出 `ΔP`、`ΔH`、欧氏 Gap、H 低估率、P 高估率和回退后的有效 P。PH 图是路由校准工具，不是主观方法定位示意图。
