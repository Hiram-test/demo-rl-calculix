# 当前 Dörfler 热点上的跨轮次资源重投与 P–H 动态路由

本实验已经按最新科学定义修正：局部误差估计和 Dörfler marking 继续负责可靠地识别“当前哪里值得加密”，LLM 不重新寻找一套替代热点；LLM 利用理论、粗网格证据、QoI 与机制先验，判断当前 Dörfler 热点在未来若干轮中是否会持续被命中、累计需要多少资源，并将若干轮一级 refinement 提前委派为区域级 macro-action。真实 FEA 仍用于发现后来显现的热点、审计重投效果和触发回退。

Stage-0B 已在 384 个参数化一维变系数椭圆有限元任务上完成三算法种子运行，测试集为 174 例，其中 139 例在长程动态 Dörfler 和给定资源上限下可达到误差容限。主要路线包括有限 H 的动态 Dörfler、当前指标重投、机制重投、带回退的机制重投、两阶段机制重投、相同当前支持上的 PSO、机制引导 PSO、one-shot 监督学习、两个轨迹 oracle 和 PH 路由。

三种子均值显示：`DORFLER_H2` 总体成功率 0.310、可行任务条件成功率 0.388、平均 H=1.83；`DORFLER_H3` 为 0.431、0.540、H=2.52；`INDICATOR_DELEGATE` 为 0.299、0.353、H=2.00；`LLM_DELEGATE` 为 0.351、0.417、H=2.00；`LLM_TWO_STAGE` 为 0.678、0.791、H=2.64，并在成功样本中相对长程动态 Dörfler平均节省 0.62 轮；`SL_ONE_SHOT` 为 0.477、0.583、H=2.00。`ORACLE_CURRENT_SUPPORT` 的条件成功率只有 0.583，而能够同时知道后来热点的 `ORACLE_FULL_TRAJECTORY` 达到 1.000，证明只把第一次 Dörfler 热点加得更深存在明确上限，至少一次真实物理刷新在当前任务族中具有结构性必要。

PSO 路线当前消耗较高：`D_SUPPORT_PSO` 平均约 7.65 次真实候选求解，`LLM_PSO` 平均约 5.77 次；当前 PH 路由器总体成功率约 0.444，主要问题是过度购买 PSO 搜索，作为校准前负结果保留。下一步先接入现有 GCN-DQN 的 D_SUPPORT_DQN 与 LLM_DQN，再用执行轨迹校准 P、H、N_FE、W_phys 和后来热点风险，随后迁移到二维/三维 CalculiX 参数化库。

核心定义与 Stage-0B 结果见 `SKILL_AND_EXPERIMENT_V2.md`；原始 Stage-0 方法矩阵保留为历史调试证据，不进入论文主结论。Stage-0B 中的机制预测仍采用冻结结构化合同，用于验证资源重投算法，不构成在线 LLM 推理能力的最终证据。
