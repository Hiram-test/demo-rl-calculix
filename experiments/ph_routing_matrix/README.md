# 机制分区—执行器矩阵与 P–H 动态路由：第一阶段可运行证据

本实验落实两类分区来源与三类执行器的完整方法矩阵：Dörfler marking 式数值分区分别连接 Dörfler、PSO、DQN；LLM 机制式分区分别连接 Dörfler、PSO、DQN；另设 one-shot 监督学习，并由 LLM P–H 路由器在验证集方法卡、机制置信度、分区一致性、先验压缩强度与物理反馈预算约束下选择路线，执行后接受真实有限元审计与保守回退。

Stage-0 采用真实装配和求解的一维变系数椭圆有限元基准，用于先验证方法接口、P–H 定义、路由逻辑、随机执行器稳定性和统计协议。算例总数为 384，包含 8 个机制族、8 个参数实例、2 个 QoI 和 3 个资源预算；训练集 168、验证集 84、测试集 132，测试集中包含 48 个完全留出的 mixed_shift 复合机制 OOD 实例。三个算法随机种子共享相同物理算例，仅改变 PSO、DQN 与监督学习随机性。

三种子测试均值显示：动态 Dörfler 分区—Dörfler 的约束成功率为 0.924、平均 H 为 2.57；LLM 机制分区—PSO 的成功率为 0.846、平均 H 为 5.00、平均在线 FE 次数为 16.37，但具有较低误差；one-shot 监督学习的成功率为 0.538、平均 H 为 1.86，体现高先验压缩与 OOD 尾部风险；完整 LLM P–H 路由的成功率为 0.924、平均 H 为 3.61、平均 FE 次数为 4.77，维持最高可靠性，但尚未降低动态 Dörfler 的平均反馈深度。DQN 路线存在明显种子方差，DM_DQN 成功率范围为 0.720–0.811。

当前结果作为方法诊断保留：路由器已经会在高压缩路线失效后回退，却会在部分软夹杂算例中过度购买 PSO 搜索；下一阶段需把预期物理信息价值、累计 FE 工作量与 OOD 风险直接纳入 P–H 路由目标，并迁移到二维板孔、L 形域、界面、边界层、多热点与诱饵 QoI 的 CalculiX 参数化算例库。完整协议见 `EXPERIMENT_PROTOCOL.md`，三种子汇总见 `results/RESULTS_SNAPSHOT.csv`、`results/seed_aggregate.csv` 与 `results/family_seed_aggregate.csv`。

边界：Stage-0 中的 LLM 机制分区与路由采用冻结、结构化、可复现的机制合同，用于验证方法协议，不构成真实在线 LLM 推理能力的最终证据；正式实验将另设冻结合同大规模测试与多模型重复调用子集。
