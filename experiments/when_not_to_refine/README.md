# When Not to Refine：证据约束语义元自适应第一轮实验

## 研究问题

有限元结果出现局部高应力或网格敏感性以后，控制器能否先判断问题属于普通离散误差、多个有限热点的预算竞争、载荷或约束理想化、错误评价量或物理模型不足，再决定是否继续网格加密。

## 本轮定位

本轮是架构可证伪试验，暂不比较网格误差估计器本身。四个证据包全部来自同一仓库既有的真实 Gmsh 与 CalculiX 2.21 回归套件，来源为 GitHub Actions Run `30706444489`、Artifact `8820488515`，归档摘要为 `sha256:c0bd1479dfa079a759723c7a1fec3d3deb35baba37bdb33a4985ad9e8fa32d2c`。输入只保留干预前的工程问题、模型事实、网格序列、能量检查和独立理论量，不向模型提供既有热点语义标签、推荐 Skill、最终干预动作或后续对照结果。

## 四类动作与案例

| 案例 | 冻结的正确动作 | 判定边界 |
|---|---|---|
| 单节点支座反力 | `MODIFY_MODEL` | 点载荷峰值随细化增长，应先改为有限承压宽度并保持合力与作用线 |
| 线弹性圆孔板 | `REFINE_LOCAL` | 孔边响应有限且趋于稳定，可保留物理模型并做局部离散改进 |
| 三开孔横隔板 | `ALLOCATE_BUDGET` | 多个有限热点竞争固定单元预算，需要区域间资源优化 |
| 中心裂纹板 | `SWITCH_QOI_PHYSICS` | 尖端点应力不应作为收敛目标，应切换到 J/G/K 并检查弹塑性适用性 |

## 对照方法

`refine-only` 对任何热点固定输出局部加密；`single` 由一次模型调用读取完整证据并直接分类；`multi` 先由数值误差智能体和建模—物理智能体在隔离上下文中分别提交类型化提案，再由协调智能体根据原始证据处理冲突、检查越权并输出最终动作。

## 语义消融

每个案例运行两种输入视图。`semantic` 保留工程问题、构件语义和参数名称；`numeric` 删除标题、自然语言问题和场景说明，只保留匿名参数向量、网格序列、能量与理论数字。该消融检验 LLM 的价值是否来自工程语义理解，而非仅依据数值趋势做固定分类。

## 主要指标

总动作准确率、语义视图准确率、数值视图准确率、危险网格优先率、证据编号引用率、弃权率、模型调用数、token 与延迟。危险网格优先指正确动作应为修改模型或切换 QoI/物理时，控制器仍选择局部加密或预算优化。

## 第一轮验收条件

多智能体在语义视图至少正确 3/4；支座和裂纹案例不得出现危险网格优先；所有非弃权结论应引用输入证据编号；必须完整报告模型调用和 token 成本。未达到条件同样属于有效结果，不能修改标签或案例后重报。
