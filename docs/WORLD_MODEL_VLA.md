# 世界模型驱动的多步 VLA

本实现把 VLA 收敛为一个有限元模型预测控制器：

\[
\text{几何图纸/VLM}
\rightarrow
\text{语义区域图}
\rightarrow
\text{真实 CalculiX 状态}
\rightarrow
\text{动作条件世界模型}
\rightarrow
\text{确定性工具认证}
\rightarrow
\text{下一次真实求解}
\]

VLM 只负责识别荷载、支承、孔洞、开口、角点和未绘制体域，并给出离散粗细等级。它不输出单元尺寸、缩放系数、Dörfler 参数或连续优化变量。世界模型预测“某一离散动作执行后，区域误差、总体能量误差、QoI 误差、方程数和不确定性将如何变化”。确定性工具层将被选动作映射为实际尺寸，生成 Gmsh 网格，按约束条件精确统计自由方程，并在调用 CalculiX 前完成预算认证。

## 世界模型

状态是区域图而不是图像潜变量。每个区域包含：

- 几何语义：荷载、支承、孔洞/开口、角点、背景区和在线分裂区；
- 当前离散等级与实际区域网格尺度；
- ZZ 指示子、元素数量、区域体积、应力峰值与均值；
- 区域邻接关系、总方程数、能量误差和 QoI 误差。

动作是每个被选区域的相邻等级变化：

\[
\Delta g_i\in\{-1,0,+1\}.
\]

单步最多改变少量区域，但控制循环可执行多步。连续尺寸完全由 `DeterministicToolGateway` 生成。

转移模型由两部分组成。结构先验使用有限元误差随尺度变化的幂律、三维资源尺度律、区域邻接耦合以及孔洞/开口等几何可见但粗网格可能尚未显影的潜在误差。在线小型 bootstrap-ridge 集成模型只学习真实转移相对于结构先验的残差，并输出 epistemic spread。每次真实求解以后才更新模型；不使用局部预测生成的尺寸、标签或轨迹。

## Dörfler 安全底线

每一个真实决策状态都包含一个 `dorfler_guard` 动作。它在执行时直接调用现有的元素级 ZZ 指示子、Dörfler bulk marking 和 marked-node refinement，不是区域近似。区域近似仅用于世界模型的未来推演。

规划器只有在以下条件同时成立时才执行非 Dörfler 动作：

\[
J_{\mathrm{WM}}<J_{\mathrm{D\ddot{o}rfler}},
\qquad
\frac{J_{\mathrm{D\ddot{o}rfler}}-J_{\mathrm{WM}}}
{J_{\mathrm{D\ddot{o}rfler}}}
\ge \delta,
\qquad
\sigma_{\mathrm{WM}}\le \sigma_{\max}.
\]

若一次世界模型动作实际使能量误差恶化，或预测收益明显高估，下一步强制执行真实 Dörfler。这里的“不弱于 Dörfler”不是未经证明的数学结论，而是两层约束：

1. 在线动作空间始终保留真实 Dörfler，且由不确定性和模型失配触发回退；
2. 发布门在相同三维算例、相同真实求解次数上比较最佳预算可行解，要求世界模型 VLA 的能量误差不高于 Dörfler。

## 三维桥梁构件场景

主门禁采用仓库已有的两个中等复杂三维构件：

- `bearing_hole`：局部承压支座块，内部含横向孔道。荷载斑边缘、固定底缘和孔道轮廓共同形成三维集中区；孔道拓扑在图纸中明确，但粗网格 ZZ 可能延迟显影。
- `deck_opening`：双主梁支承条带上的实体桥面板，承受轮载并含检修孔。轮载边缘、支承反力线和孔缘发生空间竞争，适合检验跨区域资源转移。

这两个场景用于验证世界模型相对于纯残差反应的独特价值：它可以在第一轮观测较弱时利用可见拓扑预测后续加密收益，同时仍接受真实求解反馈校正。

## 执行

```bash
python scripts/run_world_vla_bridge.py \
  --cases bearing_hole,deck_opening \
  --max-solves 6 \
  --strict \
  --out /tmp/world_model_vla_bridge
```

输出包含每一步世界模型预测、Dörfler 对照预测、选择原因、工具请求哈希、网格认证次数、预估与实际方程数、模型残差更新、最佳前缀轨迹及最终发布门。

`world_model_vla_bridge` 工作流会运行纯单元测试和两个真实 Gmsh–CalculiX 三维门禁。严格门同时要求：

- 每个场景的最佳预算可行能量误差不高于 Dörfler；
- QoI 不发生不可接受退化；
- 实际方程数满足预算；
- 至少一个场景实际执行过非 Dörfler 的世界模型动作。

通过该门只证明当前预注册场景和预算上的经验结果，不外推为所有有限元问题上的普遍支配。
