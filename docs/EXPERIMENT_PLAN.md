## 0. 一句话立论（窄问题，全篇锁死）

**在 Gmsh 重网格 + CalculiX 求解的同一管线上，"视觉分区 → 每区一个尺寸 → 子智能体一轮通信 → PSO 校准认证"的三次求解短循环（VLA 短循环），相对逐单元标记的经典 AFEM 循环、逐单元一步尺寸预测、区域图 DQN 强化学习和监督尺寸场回归，在（误差 × 自由度 × 全局求解次数 × 预算合规性 × 训练成本）五个轴上落在何处？**

假设（在 `.frd` 证据齐全前不得写成结论）：

- **H1（主假设，重网格次数）**：达到与经典 Dörfler 循环同量级的精度-资源点，VLA 短循环只需 3 次全局求解，而 Dörfler 需要 6–12 次。
- **H2（预算合规）**：在给定资源上限（方程数 N 上限）下，带 PSO 认证的 VLA 的预算超支率显著低于无认证的一步尺寸预测（后者在奇异问题上超支 40% 以上，试点已观察到）。
- **H3（免训练）**：VLA 无需任何离线训练即可达到与"监督学习（需专家网格库）"和"RL（需数百次真实求解训练）"同量级的部署表现；学习方法的离线求解成本单独入账后，VLA 的总成本最低。
- **H4（对象适配）**：在光滑热点问题（带孔板）上区域粒度足够，VLA 与逐单元方法差距缩小甚至持平；在点奇异问题（L 形角）上逐单元方法有粒度优势——两类问题都必须报告，不挑选对象。

明确不声称：VLA 在误差-自由度轴上击败按论文部署的 Dörfler（试点证据表明不成立，见 §9；这一诚实边界写入论文 Discussion）。

## 1. 背景与相关工作定位

### 1.1 问题

AMR 经典循环 SOLVE → ESTIMATE → MARK → REFINE 每轮一次全局装配求解。三维实体或非线性问题中全局求解昂贵，循环 8–12 轮的成本是工程界不用 AFEM 的主要原因之一。工程师的实际做法是"读结构、圈部位、给尺寸"，一两轮内定稿。本工作把这条工程路线形式化为可测量的算法，并与文献算法在同一管线上对照。

### 1.2 文献缺口（Related Work 四簇）

| 簇 | 代表 | 与本文关系 |
|---|---|---|
| 经典逐单元 AFEM | Dörfler 1996（bulk 标记收敛性）；Zienkiewicz–Zhu 1987（恢复型估计 + 自适应重网格）；Li–Bettess 1995（网格最优准则）；Babuška–Rheinboldt 1978（给定精度/费用停算）；Houston–Wihler 2016（局部问题预测 hp） | 对照方法，按论文对象部署（单元 K，非任何聚合） |
| RL-AMR | Yang et al. AISTATS 2023；Foucart et al. JCP 2023；ASMR/ASMR++（Freymuth et al.，每单元一个智能体 + 消息传递 + PPO） | 本文 RL 基线的定位差异：图节点是**区域**而非单元，与 VLA 的分区对象对齐（用户设定） |
| 监督尺寸场 | MeshingNet 2020 / MeshingNet3D；LAMG（arXiv:2505.20457）；AMBER（NeurIPS 2025，迭代尺寸预测 + 预算标量） | 本文监督基线：专家网格自造（无现成专家库），部署时一个预算标量对准 |
| 多模态 LLM 圈热点（**不闭环**） | GReFEM（arXiv:2607.08798，MLLM 零样本圈应力关键区、一次性预算分配、无求解器闭环）；FeaGPT / VFEAgent（对话式 FEA 编排，网格策略为规则库）；IterSIMP-σ（LLM 视觉在拓扑优化闭环中的早期对照评测） | **缺口**：已有工作证明 MLLM 能圈准热点，但没有"圈区 → 残差反馈修订 → 资源/精度校准认证"的闭环重网格协议。本文补这一环 |

### 1.3 对象选择的理由（为何主战场是 2D 平面应力）

审计（`BASELINE_AUDIT.md`）表明：上一轮 3D T 梁战役的失败根源是手写结构化六面体网格 + 冻结截面拓扑 + 自制悬挂加密，导致（i）逐单元方法无法表达 QoI 需要的跨向分辨率、"Dörfler 比均匀还差"；（ii）方法间比较被网格实现绑架。本方案的修复决定：

1. **全部重网格经 Gmsh**：任何方法的决策统一表达为尺寸场（逐单元目标尺寸图或区域尺寸），Gmsh 重新生成非结构三角网格。仓库中不存在任何手写网格操作（验收门 G2）。
2. **主战场 2D 平面应力**：单次求解亚秒级，允许 RL 训练（数百次真实求解）、多实例统计和全曲线经典循环在一天内完成；AFEM 文献的标准基准（再入角奇异）本来就是 2D 的。
3. **3D 为阶段二**：结论在 2D 成立后，同一架构换 Gmsh 3D 四面体 + C3D4/C3D10 即可迁移（§11 给出迁移卡）；T 梁几何届时作为 3D 算例回收。

### 2.1 误差原点（参考解）

- 参考网格：**解析分级参考场**——背景 h_ref，向奇异角以 r^0.55 幂律分级（角部最小 h_ref/48，对应 270° 再入角弹性奇异 λ≈0.545），向孔边以 (d/1.5r)^0.7 分级（孔边最小 0.2·h_ref）。
- 有效性验收（门 G3）：任何方法网格的应变能不得超过参考（Galerkin 单调性），`above_reference` 记录必须为零。试点两族均满足。
- 主误差：**相对能量范数误差** \(e_E=\sqrt{1-U_h/U_{ref}}\)（协调元 + 固定荷载下的 Galerkin 恒等式）；辅助误差：QoI 相对误差 \(e_{qoi}\)（加载边长度加权平均位移模）。两者分开报，不得互相替代。
- 分级参考对每个实例缓存一次（`reference.json`），不计入任何方法的求解次数。

### 2.2 试验问题集

两个参数化问题族（`visionamr/geometry.py`），每族一个 canonical 实例 + 随机实例采样器：

| 族 | 结构 | 误差机制 | canonical | 随机参数（采样器） |
|---|---|---|---|---|
| `lbracket` | 100×100 L 形支架，左边固支，右下边缘竖向荷载 | 270° 再入角**点奇异**（AFEM 经典基准） | cut=(0.5,0.5), load=−10 | cut_frac∈[0.4,0.65]²，load∈[−14,−6] |
| `plate_holes` | 200×100 带孔板，左固支右受拉 | 孔边**光滑应力集中**（工程热点型） | 1 孔 r=12 居中 | 1–3 孔，r∈[7,14]，位置带最小间距约束，tension∈[60,140] |

实例划分（锁死种子）：

- 训练集：每族 24 个实例，seeds `1000..1023`（监督专家库与 RL 训练共用采样器但种子错开：监督 `1000+i`、RL episode `2000+ep`）。
- 测试集：每族 8 个实例，seeds `9000..9007`，加 canonical。学习方法只在测试集/canonical 上评测（冻结权重）。
- 正式战役若加第三族（带圆角开槽支架），按同规则另开种子段 `3000/9100`。

### 2.3 预算档与精度目标

三档资源上限（方程数）：**N_budget ∈ {4000, 8000, 16000}**；单元预算按 elems ≈ N/1.5 换算。精度目标（供校准类方法）：err_limit = 0.7 × 探针解总指示子（默认），消融中另设显式 ε 档。每个（方法 × 问题 × 预算档）组合独立跑。

## 3. 方法部署契约（六方法，逐条对照文献锁死）

### 3.1 均匀梯子（对照，非标记方法）

h0 起步、公比 √2 的 7 档均匀网格。回答"只加自由度是否自然下降"。**不是** Dörfler 的对照替身，仅提供诊断包络线。

### 3.2 Dörfler 逐单元循环（经典对照 1）

- 对象：**单元 K**。指示子 η²_K = ZZ 恢复差能量范数（§2）。
- 标记：Dörfler 1996 bulk 标记，θ=0.5，按 η² 降序的最小基数集合（`visionamr/marking.py::dorfler_mark`，最小基数性质有单元测试）。禁止任何按区域/站/聚合后再标记。
- 加密原子：被标单元的**局部目标尺寸减半**（未标单元保持当前局部尺寸），Lipschitz 平滑后由 Gmsh 整体重网格（remeshing 实现的逐单元加密；与二分法的偏差在论文 Methods 写明，这是 Gmsh 强制约定下的标准做法）。
- 停算（按优先序）：标记集空；N ≥ 预算档；硬帽 12 轮。**误差停滞只作诊断列，永不停算**（旧实现"两三轮宣布收敛"的教训）。
- 每轮记录：cycle、N、单元数、Ση²、标记数、e_E、e_qoi、墙钟。曲线从 cycle 0 记到停，一条折线不少于 6 个点（除非空标记/预算帽提前触发）。

### 3.3 局部预测：逐单元一步多级尺寸预测（经典对照 2）

- 出处：Zienkiewicz–Zhu 1987 自适应重网格程序 + Li–Bettess 1995 网格最优准则（误差均衡）。这是"逐单元标记、一次加密很多格、一次可跨多级"的经典少求解对手。
- 部署：探针解 → 每单元 η_K → 允许误差 η_allow 由**预算模式**定（二分求解 η_allow 使预测单元数命中预算档）→ 每单元预测尺寸 h_new,K = h_K (η_allow/η_K)^{1/p}，p=1，单轮尺寸比裁剪 [1/6, 3]（允许一步跨约 2.5 个二分级）→ Gmsh 重网格。
- 轮数：**probe + 2 轮**（第 2 轮用新指示子在同一预算下修正分布），每个预算档一次独立短跑，3 次求解/档。
- 记录预算超支率 = 实际单元数/预算 − 1（试点：奇异问题第 2 轮超支 +44%，光滑问题 +59%——等分布公式不建模梯度限制带来的过渡带开销，这是该方法的固有弱点，如实报告，不做隐藏修正）。
- 与 Houston–Wihler 2016 的关系在论文中写明：HW 是"局部问题预测"的严格变体（每单元面邻居补丁 Dirichlet 局部解 + 极大值标记），本文部署的是工程经典的"指示子驱动尺寸预测"变体；HW 局部问题版列为阶段二扩展，不冒名。

### 3.4 强化学习：区域图 DQN + GCN（学习对照 1）

- 定位（用户设定，写入 Methods）：与 ASMR 等"每单元一个智能体"不同，本基线的图节点是**视觉分区产生的区域**（与 VLA 的决策对象对齐）+ 1 个背景节点；区域集在 episode 内固定（只有 VLA 有权改区域）。
- 状态：每节点 8 维特征 [log(h_i/h0), 误差份额, 单元份额, vM_max 归一, 面积份额, is_background, 剩余步数比, N/N_budget]；图卷积 Â=D^{-1/2}(A+I)D^{-1/2}，2 层 GCN（8→32→32）。
- 动作：refine 区域 i（h_i×0.7）| refine 背景 | stop。每步一次真实 Gmsh 重网格 + ccx 求解。
- 奖励（无 oracle：不用参考解）：10·Δlog√Ση² − 0.15（每步求解成本）；超预算 −2 并终止；stop 奖励按预算利用率线性（2·N/N_budget − 1），杜绝"提前停止白拿分"。
- 训练：Double DQN，回放 4000，batch 32，target 同步 200 步，Adam 1e-3，ε 1.0→0.05（60% 进度衰减）；**300 episodes × ≤8 步/族**，3 个种子 {0,1,2}；训练实例从采样器抽取。训练期真实求解数（≈300×5≈1500 次/种子）计入训练成本表。
- 评测：冻结贪婪策略跑测试集；报告 3 种子的中位数与 IQR。
- 试点（40 episodes 演示规模）：策略已学会先加密角区/孔区并用满预算的 60–80%，但精度仍落后经典方法——训练规模是主变量，正式战役必须跑满 300×3。

### 3.5 监督学习：专家尺寸场回归（学习对照 2）

- 专家网格自造（用户确认无现成专家库，单独开一条数据线）：对每个训练实例跑 §3.2 的 Dörfler 循环至预算帽，其末代网格的节点尺寸场即"专家标签"。
- 模型：逐节点 MLP（8→64→64→1），输入特征 [归一坐标 x̂ŷ, log vM 归一, log η 结点归一, 到固支/荷载/最近特征的归一距离, h0/diam]，输出 log(h/h0)；MSE，Adam 2e-3，300 epochs。
- 部署（2 次求解）：探针解 → 特征 → 预测节点尺寸场 → **一个预算标量 c** 二分对准预算档（MeshingNet/AMBER 式标量旋钮；单元数估计按探针网格实测校准）→ Gmsh 重网格 → 终解。
- 训练成本入账：24 实例 × Dörfler 全循环 ≈ 24×8 次求解。

### 3.6 VLA 短循环（主方法）

三次全局求解，全部经 `FemRunner` 记账：

```
solve 1  probe      h0 均匀网格（视觉输入 + 残差源）
solve 2  regional   视觉分区 + 一轮子智能体通信协商出的区域尺寸场
solve 3  certified  PSO 校准后的区域尺寸场（认证解）
```

**(a) 视觉分区**（`visionamr/vla/partition.py`）。两个视觉头：

- `LLMVisionPartitioner`（正式战役主头）：探针解 von Mises 场渲染 PNG → 多模态 LLM（OpenAI 兼容接口，严格 JSON schema：区域名/盒坐标/尺寸分数）→ 区域列表。**区域个数跟视图走**，禁止固定模板；提示词允许对最热部位画嵌套框。
- `ScriptedVisionPartitioner`（可复现替身 + 视觉质量消融下界）：vM 0.90 分位阈值 → 网格图连通域聚类 → 特征命名（就近特征锚点：孔/角/固支/荷载）→ 委派尺寸按强度插值 [0.22, 0.55]·h0 → 最热簇发嵌套内框（0.38 线尺寸、0.45×外框尺寸）。每个框仍只有一个尺寸——嵌套实现区域级分级，不违背"每区一尺寸"约定。

**(b) 一轮通信**（`visionamr/vla/agents.py`）。每区域智能体读自身（误差/资源份额 vs 面积比例目标）、邻居（尺寸平滑耦合 0.08）、父智能体（全局预算压力 0.6/d），做一次有界对数步：

\[
\Delta_i=\mathrm{clip}\Bigl(\frac{w_r d\, r_{\log}-w_e p\, e_{\log}}{w_e p^2+w_r d^2+\lambda},\pm 0.35\Bigr),\quad
w_e=4,\ w_r=1,\ \lambda=0.5,\ p=1.3,\ d=2
\]

（d=2 是 2D 资源维数；三维迁移时 d=3。）邻接由区域盒膨胀重叠 + 最近邻兜底构成。

**(c) 区域编辑权**（仅 VLA 有）：solve 2 后若背景残差份额 > 30%，把背景最热簇提升为新区域（≤2 个）。RL 基线无此权（区域固定），这正是"VLA 可改自己的区域、RL 不需要"的用户设定。

**(d) PSO 校准认证**（`visionamr/vla/pso.py`）。决策变量只有 2 维 (s, κ)：h_i(s,κ)=h_i·exp(s+κτ_i)，τ 为按边际效率构造的资源中性转移方向（去均值、归一化）；幂律代理逐区域拟合指数 q_i=Δlog(Ση²_i)/Δlog h_i（由 solve 1、2 两个真实观测拟合，裁剪 [0.6,4]），**代理锚定在 solve 2 的名义尺寸上使母粒子 (0,0) 严格自洽**；适应度 = 200·max(log E/E_lim,0)² + 200·max(log R/R_bud,0)² + 2·max(−log R/R_bud,0)² + 50·邻比>1.8 罚 + 0.05(s²+κ²)。粒子群 9 粒 × 6 代 + 闭式种子（预算尺度 s*=½log(R₀/budget)、精度尺度 s_E=log(E_lim/E₀)/q̄），seed=17。仅代理评估，无额外求解；胜者由 solve 3 认证。
- κ≈0 的读法（预登记）：空间再分配已由通信轮完成、PSO 退化为全局比例——与连续网格嵌入族一致，**不是失败**。
- 门（G4）：三次求解的 N 两两互异；撞车记 failure_scenario，不造第三个点。

**(e) 连续变体（消融用）**：`extra_rounds ∈ {0,1,2}` 在 regional 与 PSO 间插入额外"通信+求解"轮，对应"不停决策"的 VLA 长循环思路，用来量化"多一轮通信值多少精度、费多少求解"。

试点证据（canonical，预算 8000，Scripted 头）：L 形 3 次求解 e_E 0.348→0.096→**0.083**（认证步同时降误差与降资源 6518→5513 单元，预算超支仅 +3.4%）；带孔板 0.172→0.044→**0.034**（PSO 主动加密 s=−0.084 因精度限起作用）。三 N 互异门两族均通过。

## 4. 比较协议（回答"怎么比"）

四张主对比轴，全部同时报告，禁止只挑有利轴：

| 轴 | 定义 | 回答什么 |
|---|---|---|
| A1 误差–自由度 | e_E（及 e_qoi）对 N，log-log | 经典问题：每个自由度花得值不值 |
| A2 误差–全局求解次数 | e_E 对该方法累计 ccx 次数（探针也计入） | **主叙事轴**：重网格次数省在哪 |
| A3 预算合规 | (实际 N/预算 − 1) 对 e_E 散点，按预算档分面 | 给定上限时谁敢签字 |
| A4 训练成本 | 部署期求解数 + 离线训练求解数（RL≈1500×3；监督≈200；经典与 VLA=0）条形图 | 端到端总成本 |

读图纪律：

1. A1 上不同方法的加密原子不同（逐单元尺寸图 vs 区域尺寸场），题注必须写明；不做单一"假 Pareto"排名。
2. A2 上局部预测每个预算档是独立短跑（3 次/档），画档内曲线，不把三档拼成一条假收敛线。
3. 匹配点读法：报告"预算档 8000 处"三元组（e_E, 实际 N, 求解次数）总表（论文主表）。
4. 测试集统计：8 实例 + canonical，报中位数 [IQR]；RL 3 种子再取中位。显著性用 Wilcoxon 符号秩（配对到实例），α=0.05，只对 H1–H3 的预登记比较做检验。

## 5. 消融实验（VLA 内部，canonical × 2 族 × 预算 8000）

| 消融 | 变体 | 检验什么 |
|---|---|---|
| AB1 视觉头 | LLM 头 vs Scripted 头 vs 随机盒（区域数同 Scripted） | 视觉质量对短循环的贡献；随机盒是下界 |
| AB2 通信轮 | 有 vs 无（委派尺寸直接进 PSO） | 一轮邻域/父级通信值多少 |
| AB3 PSO 认证 | 有 vs 无（regional 即终解，2 次求解） | 校准步的误差/预算收益（试点：两族认证步均同时改善误差与预算） |
| AB4 区域编辑 | 允许 vs 禁止 | 背景热区提升的价值 |
| AB5 嵌套框 | nested_top ∈ {0,1,2} | 区域级分级对奇异问题的粒度补偿 |
| AB6 连续变体 | extra_rounds ∈ {0,1,2} | 短循环 vs"不停决策"的边际收益 |
| AB7 PSO 维度 | (s,κ) vs 仅 s vs 逐区域全维 Nelder-Mead | 低维校准是否足够（回应"PSO 维度=区域数"的旧评审意见） |

## 9. 试点结果登记（demo 规模，正式战役前的基线事实）

## 10. 风险与预案

| 风险 | 等级 | 预案 |
|---|---|---|
| LLM 视觉头输出不稳定（区域漂移/JSON 失败） | 高 | 严格 JSON schema + 温度 0.1 + 3 次重试；失败实例记录并回退 Scripted 头（论文如实报告回退率）；AB1 量化两头差距 |
| RL 300 eps 仍学不过经典方法 | 中 | 如实报告（RL 定位本来是"之前尝试的说明性对照"，用户原话）；附训练曲线与失败分析 |
| 局部预测超支被审稿人视为部署错误 | 中 | Methods 写明等分布公式不建模梯度限制带（引 Li–Bettess 的已知讨论），并给出"再加一轮即可回预算"的对照数据 |
| 区域粒度在奇异问题吃亏被读成 VLA 失败 | 中 | §0 预登记 H4；嵌套框消融 AB5 展示粒度补偿路径 |
| 2D 结论被质疑不代表 3D | 中 | §11 迁移卡 + 阶段二 T 梁算例（几何已有） |
| Gmsh 版本差异导致网格微差 | 低 | 版本锁定 + 结果对网格扰动的敏感性检查（同配置 3 个 Gmsh 随机因子） |
