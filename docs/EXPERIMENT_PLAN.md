## 0. 一句话立论（窄问题，全篇锁死）

**在三维桥梁构件（支座板局部承压、梁桥面板轮载）上，"视觉播种子长成类人分区 → 每区一个尺寸 → 子智能体一轮通信 → 区域分裂 → (s,κ) PSO 预算硬帽校准"的自适应短循环（VLA，≤k 次全局求解，k=4–6），能否在少量求解次数处击败按论文部署的逐单元 ZZ–Dörfler 循环？**

主目标是**少求解次数区间**（k=2..6）的误差优势与到达给定精度的求解次数加速比；**渐近最优性明确让给 Dörfler**（这是它的定理，本文不争、并如实展示交叉点）。

预登记假设（`.frd` 证据齐全前不得写成结论）：

- **H1（主假设）**：k∈{2,3,4} 处 VLA 的能量误差低于 Dörfler 同求解次数的误差；到达 Dörfler 第 4 轮精度水平，VLA 加速比 ≥ 1.5×（按求解次数）。
- **H2（预算合规）**：预算硬帽语义下（PSO 认证含预算投影），VLA 终解方程数落在预算的 [90%, 105%]；无认证的一步尺寸预测显著偏离（欠用或超支 ≥20%）。
- **H3（免训练）**：VLA 无离线训练即达到与监督学习/RL 部署表现同量级；训练求解成本单列后端到端总成本最低。
- **H4（交叉点诚实声明）**：存在 k*（试点约 5），k≥k* 后 Dörfler 反超——论文明确给出交叉点而不是隐藏它。

**试点主表（headline，能量误差 @ 第 k 次全局求解，Scripted 视觉头，确定性网格生成，本仓库实跑）：**

| k | 支座 Dörfler | 支座 **VLA** | 面板 Dörfler | 面板 **VLA** |
|---|---:|---:|---:|---:|
| 2 | 0.375 | **0.212** | 0.601 | **0.351** |
| 3 | 0.291 | **0.198**（就地认证，止） | 0.492 | **0.351** |
| 4 | 0.210 | —（已 3 次交付） | 0.388 | **0.341** |
| 5 | 0.143* | — | 0.274 | — |

*Dörfler 第 5 轮超出资源预算 17%（支座 9354>8000）。VLA 交付解预算占用：支座 94%（3 次求解就地认证）、面板 83%。VLA 列为"交付解"：已求解、预算合规轮中按**自身指示子**选优（return-best-iterate 语义，不用参考解挑点）。

## 1. 背景与相关工作定位

### 1.1 问题

AMR 经典循环 SOLVE→ESTIMATE→MARK→REFINE 每轮一次全局求解。三维实体构件上全局求解昂贵，8–12 轮的成本正是工程界不用 AFEM 的原因。工程师的真实做法是"读图 + 读云图，圈几块部位，各给一个尺寸，一两轮定稿"。本文把这条路线形式化，并以"误差 @ 第 k 次求解"为主轴与文献算法对照。

### 1.2 相关工作四簇

| 簇 | 代表 | 与本文关系 |
|---|---|---|
| 经典逐单元 AFEM | Dörfler 1996；Zienkiewicz–Zhu 1987；Li–Bettess 1995；Babuška–Rheinboldt 1978 | 对照方法，按论文对象部署（单元 K）；渐近最优性归它 |
| RL-AMR | Yang 2023；Foucart JCP 2023；ASMR/ASMR++ | RL 基线图节点=分区区域（非单元），与 VLA 决策对象对齐 |
| 监督尺寸场 | MeshingNet / MeshingNet3D；LAMG；AMBER | 监督基线：专家网格自造 + 预算标量 |
| 多模态 LLM 圈热点（不闭环） | GReFEM（MLLM 零样本圈应力关键区、一次性预算分配、无闭环）；FeaGPT / VFEAgent；IterSIMP-σ | **缺口**：会圈热点但没有"分区 → 残差修订 → 预算硬帽认证"的闭环重网格协议。本文补这一环 |

### 1.3 对象：三维桥梁构件（主战场）+ 2D 基板（开发/CI）

**主战场（3D，C3D4 四面体，Gmsh HXT）：**

| 族 | 结构 | 误差机制 | 工程原型 |
|---|---|---|---|
| `bearing_block` | 400×400×120 mm 支座板，底面固支，顶面偏心补丁压力（压印进几何） | 补丁边 4 条奇异线 + 底面固支周边反力线 | 支座上座板/垫石局部承压 |
| `deck_panel` | 2400×1600×200 mm 桥面板，底面两条主梁支承条带（压印，条带内 \(u_z=0\)），顶面轮载补丁（压印） | 轮载下弯曲热点 + 条带内缘反力线 | 梁桥行车道板轮载验算 |

关键工程化细节（v2 教训，锁死）：**荷载/约束足迹必须压印进 OCC 几何**（`occ.fragment`），使任何网格都精确剖分补丁与条带边界——否则受载面积随网格漂移，能量误差非单调（v2 试点已实证并修复）。荷载合力已验证在任意网格下精确等于 p×A。

**2D 基板**（`lbracket` 角奇异、`plate_holes` 孔热点）：保留为快速开发、单元测试与 CI 的 G1 门载体；学习方法的低成本演示也在 2D。论文主文只报 3D。

采样器：支座（补丁尺寸 100–180、偏心 ±70、压强 8–16 MPa）；面板（轮位 x∈[700,1700] y∈[500,1100]、轮压 0.7–1.4 MPa、补丁 300–500×200–320）。实例划分：训练 24（seeds 1000..1023）/ 测试 8（seeds 9000..9007）+ canonical，学习方法只在测试集评测。

## 3. 方法部署契约

### 3.1 均匀梯子（对照）

公比 \(2^{1/d}\)（每档单元数翻倍），至预算帽止。回答"只加自由度"。

### 3.2 Dörfler 逐单元循环（经典对照 1，渐近最优的一侧）

对象=单元 K；ZZ 指示子；bulk 标记 θ=0.5（最小基数，单测锁定）；被标单元局部尺寸减半 → Gmsh 重网格；停算=空标记/N≥预算/12 轮硬帽；误差停滞只作诊断。曲线从 cycle 0 全程记录。

### 3.3 局部预测：逐单元一步多级尺寸预测（经典对照 2，少求解的一侧）

ZZ 1987 自适应重网格 + Li–Bettess 最优准则。**v2 修正（锁死）**：预测指数取局部理论速率 \(\eta_K\sim h^{(d+2)/2}\)（2D 指数 2、3D 指数 2.5）；单轮尺寸比裁剪 [1/6, **1.8**]（粗化界收紧——3D 试点实证 p=1 且宽粗化界会把体域粗化 3 倍换奇异线，误差反弹 0.18→0.30，属该方法已知失稳模式，修正后单调）。每预算档独立短跑：probe+2 轮=3 次求解。预算偏差率如实入指标。

#### 3.3.1 局部预测的已知缺点（轻调研）与 VLA 对位机制

文献核对（一步/少步单元级尺寸预测的缺陷是老问题，不是本文杜撰）：

- **振荡**：Oñate–Bugeda 1993（Engineering Computations 10:307）指出"误差范数收敛率评估不正确……是细化过程振荡的根源"；UPC 统一重网格研究（Fuenmayor 等，CMAME 1999 系）在 ZZ 自家的重力坝奇异算例上复现："ZZ 重网格策略在该问题上振荡，源于部分区域的交替细化与粗化"；其改型（禁止粗化）则"单元过多且部分区域精度仍不足"。本仓库 3D 支座试点独立复现了同一失稳（0.18→0.30 反弹）与改型代价（预算超支）。
- **假设失效**：ZZ 准则依赖"误差能量密度在旧单元内为常数"的附加假设（同上 UPC 文），奇异线邻域不成立；Almeida Pereira–Bugeda 1999 为奇异问题专门提出非均匀误差分布准则。
- **预渐近指示子噪声**：粗探针上 ZZ 有效性指数远离 1，逐单元预测将单元级噪声直接写进尺寸场。
- **预算无认证**：等分布公式不建模梯度限制带与网格器行为，实测偏差 −26%～+59%，且无任何"给定上限必守"的机制。
- **只看场**：粗探针下尚未显影的误差源（支承反力线）不会被指示子看见。

**缺点 → VLA 对位机制 → 本仓库实现（每条均有消融）：**

| 局部预测缺点 | VLA 机制 | 实现 |
|---|---|---|
| 假设光滑收敛率 → 奇异区振荡 | **不预测下一轮误差**。PSO 用上次实测 η² 份额分配细化，不用 η~h^q | `calibrate_measured` + `transfer_from_measure` |
| 单元级噪声放大 | 区域聚合（几十~千单元求和）天然降噪 | `Partition.features` |
| 预算失配（梯度带开销不可建模） | 单元数缩放 N~h^{-d} + 实测**资源漂移**（realized/predicted elems）；硬帽只许收紧 | `resource_elems` / `resource_drift`，clip [1.0,1.4] |
| 轮间大幅跳动 | 有界对数步 + 邻域耦合 + 后期轮 PSO 信任域（0.8→0.45） | `pso_pos_bound_later` |
| 无认证 | 预算硬帽投影（终轮安全系数 0.85）+ 交付=合规轮指示子最优。早停看**实测** Ση²，不用 E_pred | `final_budget_safety` / certified_pick |
| 看不见图纸知识 | 结构锚点种子（支座边缘反力线、条带三分点） | `ScriptedVisionPartitioner.anchor_kinds` |

### 3.4 RL：分区图 DQN + GCN（学习对照 1）

图节点=**分区区域**（非单元；区域集 episode 内固定，只有 VLA 可改分区）。特征 8 维（log 尺寸、误差/单元份额、vM、体积份额、实测平均尺寸、剩余步数、预算占用）；2 层 GCN → 每区 Q + 全局 stop-Q。动作=某区尺寸×0.7 或 stop；每步一次真实重网格+求解。奖励无 oracle：10·Δlog√Ση² − 0.15/步；超预算 −2 终止；stop 奖励=2·(N/预算)−1（预算利用率导向）。Double DQN；正式战役 300 eps × 3 种子/族（2D 基板全量；3D 试点档缩减为 120 eps 并如实报告规模）。

### 3.5 监督学习（学习对照 2）

专家=Dörfler 循环跑到预算帽的末代网格节点尺寸场（24 训练实例自造）；9 维节点特征（含 ẑ）→ MLP 64×64 回归 log(h/h0)；部署=探针+预算标量（按探针网格实测校准单元数估计）+ 一次重网格 = 2 次求解。

科学边界（锁死，写入 Discussion）：监督不是 AMR 的替代物，是对已付清的经典循环做压缩。标签预言机就是 Dörfler；无限覆盖一切拓扑的专家库在定义上已经先跑完对照方法，再在部署时做一次探针前馈。单件桥梁图纸摊销不起「先对每个拓扑类造库」。部署信息瓶颈独立于容量：一步回归只能看见当前探针，探针没显影的图纸特征（孔缘 η² 份额几个百分点）发明不出来。VLA 多出来的是图纸种子通道与在线短循环，不是更大的库。禁止把「未见拓扑 / 冻结母族」写成科学结论。

### 3.6 VLA 自适应短循环（主方法，v2）

**决策对象：类人分区，绝不是盒子。** 视觉头先在正交视图上**画出不规则区域**（多边形笔划，不是轴对齐 box，也不是只丢种子再测地线填色），再由眼睛给每一区一个尺寸（`fineness_fraction × h0`）。允许拆结构剖面（`view=section` + `plane` + `cut`），剖面只作用在剖切附近。单元投影落在哪块笔划里就归哪区，更细的区覆盖重叠；**没画到的体积也要眼睛委派** `remainder_fineness_fraction`，不是自动 h0。盒子只留作 AB2 消融。区域分裂（残差集中再画一小块）只留 AB4；主方法不重画多边形。

**视觉头两个（消融轴）：**
- `LLMVisionPartitioner`（正式主头）：看**图纸**正交视图（不是应力云图）→ JSON 多边形 + 每区尺寸 + remainder。
- `ScriptedVisionPartitioner`（可复现替身）：只圈图纸锚点（补丁、支承、角、孔），不读求解场。

协议由 skill `.cursor/skills/vla-real-workflow/SKILL.md` 锁死。

**算法（真实流程，≤ max_solves 次全局求解）：**

```
读图（0 次求解）：不规则区 + 相对粗细（含 remainder）
solve 1  first：已画网格上的第一次分析（不是均匀 h0 探针）
一次修订：h_i = h_eye_i exp(s+κτ_i)，多边形不重画；不许通信轮按 η 重谈
solve 2  certified
```
通信 / 分裂只留 AB4 / AB5。主方法是一两轮定稿。

**PSO 校准（不花求解）**：变量 (s,κ)，\(h_i=h_i^+\exp(s+\kappa\tau_i)\)，τ 来自上次实测残差密度（`transfer_from_measure`，不拟合 q）。适应度只用上次 Ση² 份额 + 单元数缩放 \(N\sim h^{-d}\) + 邻比罚 + 硬预算投影（常规轮安全系数 0.97、终轮 0.85；漂移只收紧，clip [1.0,1.4]）。**没有误差代理**：不回归 η~h^q，不预测下一轮 E_pred。那是 LP 的假设，PSO 不需要它。早停看实测 Ση²。**交付语义**：已求解、预算合规轮中按自身指示子选优（第一次求解已是画过的网，可以成为交付）。精度限=0.25×第一次求解总指示子。

试点行为数字来自改前（幂律适应度 + 均匀探针）战役，**尚未用新初始化重跑**。不要把下面数字写成新协议的结果。旧记录：支座（预算 8000）13 区，0.476→0.212→**0.198**@7500；面板（预算 20000）14 区，0.706→0.351→0.376→**0.341**@16628。

### 3.7 求解次数记账

对照方法的均匀探针计为第 1 次求解；VLA 的第 1 次求解已经是画过的网。学习方法训练期求解单列。VLA 的 PSO 不花求解，适应度用上次实测残差和单元数缩放，不预测下一轮 η。

## 4. 比较协议

| 轴 | 定义 | 地位 |
|---|---|---|
| **A2′ 误差@k 次求解** | 每方法第 k 次全局求解后的 \(e_E\)（k=1..6 表格+曲线） | **主轴（论文主表/主图）** |
| A2″ 加速比 | 到达 Dörfler 第 4/6 轮误差水平所需求解次数之比 | 主轴衍生 |
| A1 误差–自由度 | \(e_E\)–N log-log；题注声明加密原子不同 | 次轴（交叉点与渐近让位在此展示） |

| A4 训练成本 | 部署求解 + 离线求解（RL≈600–1500×3；监督≈200；经典/VLA=0） | 端到端成本 |

| AB9 实测指数协商 | 接线保留；主循环不再拟合 q（那就是误差代理） | 对位 Oñate–Bugeda 的旧机制已退出 |
| AB10 漂移反馈 | 开 vs 关；终轮安全系数 ∈ {0.85, 0.92, 0.97} | 预算合规带宽与误差的权衡 |
| AB11 就地认证 | 接线保留；主循环不再用 E_pred 就地停 | 旧代理早停已退出 |

## 9. 试点登记（demo 规模，正式战役前基线事实）

3D 主表见 §0。补充（canonical，试点预算档）：

**支座（8000 eq）**：均匀 h5 0.203@11763；Dörfler 5 轮 0.143@9354（超预算 17%）；局部预测 b12903 三次求解 0.179@5961（欠用 25%）；VLA **3 次**就地认证 0.198@7500（94%）。
**面板（20000 eq）**：均匀 h5 0.326@35875；Dörfler 5 轮 0.274@17821、6 轮 0.157@38050（超预算 90%）；局部预测 b32258 三次 0.269@17552（88%）；VLA 4 次 0.341@16628（83%）。
**2D 基板**（回归口径，G1 载体，预算 8000）：Dörfler 匹配 N 处约 3× 优于均匀；局部预测新指数后 b4000 三次求解 0.047@7733。VLA 在 2D 于第 2 次求解即提前认证（自适应求解数的另一方向）：L 形 0.098@7704（96% 预算，≈Dörfler 第 4 轮水平）、带孔板 0.049@6743（84% 预算，≈Dörfler 第 4 轮水平）。学习方法演示规模：监督 2 次求解 0.050@8702（L 形）；RL 40 集不足额训练，徘徊在 0.17（L 形），正式战役按 §3.4 规模执行。

诚实边界（写入 Discussion）：k≥5 后 Dörfler 反超（H4 交叉点）；局部预测在部分 k 点的能量误差低于 VLA（其预算行为差、无认证语义）；3D RL/监督为演示规模。监督的科学限制是标签循环与探针信息瓶颈，不是覆盖度；E3/E4 不升格为 H1–H4。
