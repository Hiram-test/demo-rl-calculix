# 重写切片 01：问题清单与参数来源

本切片只建立新架构的第一条边界，不实现任何案例专用模型。

## 已实现

- 当前任务的 `ProblemManifest`；
- 每个事实、假设和算法配置的来源标签；
- 缺少物理参数时生成用户问题，不静默补默认值；
- 物理模型事实与 PSO 次数等算法配置严格分离；
- 旧 benchmark 值只能显式标成 `legacy_fixture`；
- 所有检查只形成记录，不形成阻断流程的门禁。

## 本切片明确不包含

- `1000 mm`、`40 mm`、固定材料、固定荷载等案例值；
- 支座、圆孔、裂纹等案例专用 builder；
- 固定 PSO 粒子数、代数和 solver 次数；
- `PASS/FAIL` 式工程结论；
- 因缺参或格式问题而禁止后续报告。
