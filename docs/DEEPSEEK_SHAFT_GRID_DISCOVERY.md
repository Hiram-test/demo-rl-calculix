# DeepSeek 圆轴表面标线与网格方向烟测实验

## 当前目标

先验证完整闭环能够稳定运行，再引入真实有限元边界和求解器。DeepSeek 仍然只看到普通工程师提出的结果型问题，不会看到竞赛名称、原题编号、变量符号、特殊角度答案、解析公式、工具目录或后台预算。

## 当前后端

当前 `solve()` 不调用 CalculiX，也不建立端面载荷或位移边界。它直接把均匀圆轴拉扭解析位移场采样到可旋转、可细化的圆柱表面网格节点上，因此仍然保留本阶段需要验证的数值现象：最近节点取点会受到正交或斜交网格方向影响，网格细化会改变节点吸附误差，精确端点插值会恢复连续体方向响应。

## 闭环范围

烟测继续覆盖工程问题输入、DeepSeek 多轮提案、提案冻结与哈希链、隐藏动作映射、网格方向对照、网格细化对照、提取协议对照、一维粒子群角度搜索、隐藏解析评分和不同载荷比例盲测。所有接口都与后续真实有限元后端保持一致。

## 执行顺序

第一阶段只要求静态合同测试、真实 DeepSeek 调用、多轮轨迹、隐藏评分和结果写回完整跑通。当前结果不能被描述为真实 CalculiX 验证。烟测通过后，再单独设计最简单的真实有限元载荷与边界，并逐项替换轻量后端，避免把建模错误、求解器兼容问题和智能体判断问题混在同一轮实验中。
