# DeepSeek 圆轴表面标线与网格方向发现实验

## 目标

本实验把一个具有独立解析真值的拉扭表面材料线问题包装成普通工程师会提出的结果型问题。DeepSeek 看不到竞赛名称、原题编号、变量符号、特殊角度答案、解析公式、工具目录和后台预算。它只看到工程师希望得到的标线推荐角度、材料与载荷事实，以及若干真实 CalculiX 初算结果。

## 工程师可见问题

工程师只说明圆钢轴同时承受拉力和扭矩，准备在表面画一条短斜线，希望这条线受力后的方向变化尽量明显；已有有限元结果会随网格大小和排列方向改变，因此需要一个可直接采用的角度和网格建议。问题中不要求研究假设、实验轮数、优化算法或评分方法。

## 隐藏研究问题

实验在后台检验 DeepSeek 是否能够自行发现：标线初始方向是连续设计变量；加载前后方向变化是需要最大化的观测量；标线不改变结构刚度，因此一个真实位移场可以廉价评价大量方向；等单元数旋转网格能够区分网格方向效应；同方向逐级细化能够区分方向效应和分辨率效应；最近节点吸附可能制造与网格贴合有关的假最优值；精确端点表面插值能够降低该偏置；连续黑箱搜索可以由粒子群或其他方法完成；最终结论必须在旋转网格、细化网格和不同拉扭比例下保持稳定。

## 有限元模型

后端生成一个直径八十毫米、长度一百毫米的三维实心圆轴观测段。截面中心使用 C3D6 三棱柱，外环使用 C3D8 六面体。圆周、径向和轴向划分独立可控。各轴向截面可以按给定相位连续旋转，因此表面轴向网格线可以形成零度到三十度的可控螺旋方向，而实体几何仍保持同一圆柱。两端施加与均匀拉伸和圣维南扭转一致的位移边界，CalculiX 输出全部节点位移。

## 两种标线提取协议

第一种方法把标线两端吸附到最近表面节点。这是容易实现的工程后处理，但会把连续方向离散成少数网格节点连线，因此可能产生网格方向偏置。第二种方法保持标线真实端点，在所在螺旋表面四节点单元内插值两端位移，再计算变形前后方向差。两种方法使用同一个有限元位移场，能够把结构离散误差和结果提取误差分开。

## DeepSeek 隔离合同

本实验堆叠在 PR #18 的隐藏执行器分支之上。每轮 DeepSeek 只用工程语言提出一个下一步检查或计算，并至少保留两个竞争解释。提案先写入磁盘并加入 SHA256 哈希链，之后隐藏执行器才判断能否忠实映射为等规模网格方向对照、逐级细化、结果提取对照、连续方向搜索、独立理论校核、信息补充或停止。无法保持原目的时返回不支持，不替换成预设路线。

## 防背诵设计

可见工况采用一百八十千牛拉力和二千牛米扭矩，隐藏解析最优角并不是原题特殊比例对应的二十二点五度。最终冻结后，评分器再用一百二十千牛和二百四十千牛两个未见工况执行真实有限元盲测。固定回答某个著名角度无法通过。

## 评分

隐藏评分同时检查最终推荐角与可见工况解析真值的误差、最终数值方法在两组未见载荷比例上的误差，以及模型是否主动涉及方向变量、连续搜索、网格方向、网格细化、结果提取协议和独立校核。总体通过还要求模型实际讨论网格方向、网格细化和提取偏置，不能只给出一个碰巧正确的角度。

## 隔离边界

全部新增代码位于 `experiments/shaft_grid/`、一个独立运行脚本、一个测试文件、一个工作流和本说明文件。现有裂纹实验、论文工作流、Skill、旧结果目录和 PR #18 的执行器文件保持不变。真实运行结果写入独立目录 `experiments/results/latest_deepseek_shaft_grid_discovery/`。
