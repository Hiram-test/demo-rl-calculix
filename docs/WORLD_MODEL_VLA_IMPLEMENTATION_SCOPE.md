# Implementation scope

This branch contains one controlled implementation path: a cached semantic VLA partition, an action-conditioned regional world model, finite-horizon planning, deterministic MCP-shaped parameter materialization, exact Dörfler fallback, and a paired three-dimensional steel box-girder diaphragm benchmark.

The implementation intentionally excludes local-prediction target fields, PSO, continuous LLM parameter tuning, and mixed-method labels. Superiority is reported only after the paired real-solver gates pass.
